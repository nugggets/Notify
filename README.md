# Notify (Android)

Маленькое приложение-приёмник для **второго телефона**. Открывает в Chrome ссылки на заказы,
которые вы отправляете с первого телефона кнопкой «📲 Открыть на втором телефоне» в ProfiMonitor (версия 4.5 и новее).
Остальные заказы на второй телефон не приходят.

## ⚡ Как выпустить версию (читать первым, особенно новому чату)

Проект лежит на телефоне в **Termux** (не Debian) в папке `~/notify`. Это отдельный репозиторий на GitHub (не ProfiMonitor).
Архив версии лежит в «Загрузках» и называется `Notify-vX_Y.zip` (в имени подчёркивания, например `Notify-v1_1.zip`).

**Обновление версии.** Одним блоком в Termux, подставьте номер версии вместо `X_Y` и `X.Y`:

```
cd ~/notify; unzip -o ~/storage/downloads/Notify-vX_Y.zip; grep -c "ReceiverService" app/src/main/AndroidManifest.xml; git add -A; git commit -m "vX.Y"; git pull --no-rebase -X ours --no-edit; git push
```

`grep -c` должен напечатать `1`. Если `0`, архив распаковался неполностью: не продолжайте.
Пуш в `main` сам запускает GitHub Actions («Build APK»). Готовый APK (`Notify-vX.Y.apk`) появится в разделе Releases и в артефактах запуска.

**Самый первый запуск** (репозитория на телефоне ещё нет). Сначала на github.com создайте пустой репозиторий `notify`
(без README и .gitignore), затем один блок. Адрес берётся из репозитория ProfiMonitor (`~/profimonitor`), меняется только имя репозитория:

```
mkdir -p ~/notify; cd ~/notify; unzip -o ~/storage/downloads/Notify-v1_1.zip; grep -c "ReceiverService" app/src/main/AndroidManifest.xml; git init -b main; git add -A; git commit -m "v1.1"; git remote add origin "$(git -C ~/profimonitor remote get-url origin | sed 's#[^/:]*$#notify.git#')"; git push -u origin main
```

**Правило для ассистента (нового чата):** в каждом ответе, где выдаётся новый архив Notify, в конце обязательно давать этот блок
команд одним фрагментом кода, уже с подставленным номером версии (имя архива, коммит), без дополнительных объяснений.
Пользователь пишет по-русски, отвечать по-русски. Каждая версия описывается отдельным разделом ниже.

## Как пользоваться
1. Установите APK на второй телефон. Откройте Notify, разрешите уведомления.
2. В ProfiMonitor на первом телефоне: Настройки → «Второй телефон» → «Код связи» → «Создать новый» (код скопируется).
3. В Notify на втором телефоне нажмите «Вставить код из буфера», затем «Сохранить и запустить приём».
4. Нажмите «Поверх других приложений» и «Не ограничивать батарею» и включите разрешения. Без первого Android 10+ не даёт открыть Chrome из фона: тогда придёт уведомление, по нажатию на него откроется ссылка.
5. «Проверить: отправить себе ссылку» открывает на этом телефоне profi.ru: так видно, что связь работает.
6. В ProfiMonitor откройте заказ и нажмите «📲 Открыть на втором телефоне».

На втором телефоне в ProfiMonitor переключатель «Этот телефон принимает ссылки» лучше держать выключенным: приём делает Notify.

## Как устроено
Ссылка идёт через бесплатный сервис ntfy (по умолчанию `https://ntfy.sh`). Оба приложения знают один секретный **код связи**
(имя темы ntfy, 24 случайных символа). Notify держит соединение с темой (`ReceiverService`, служба на переднем плане с постоянным
уведомлением, не даёт процессору засыпать, поэтому второй телефон лучше держать на зарядке) и открывает пришедшие ссылки в Chrome,
а если Chrome нет, в браузере по умолчанию. Принимаются только ссылки на `profi.ru`, если не включена галочка «Принимать любые https-ссылки».
Ссылки старше двух минут игнорируются (после обрыва связи старые не откроются). После перезагрузки телефона и обновления приложения приём запускается сам.

Файлы: `Link.kt` (протокол и проверка ссылки), `ReceiverService.kt` (приём), `MainActivity.kt` (экран), `Cfg.kt` (настройки и журнал), `BootReceiver.kt` (автозапуск).
Подпись APK: постоянный ключ `app/debug.keystore` в репозитории, поэтому новые сборки ставятся поверх старых.

## Версия 1.1 (исправление: ссылки не доходили)
- Часы телефона больше не участвуют в отборе сообщений. Раньше при расхождении часов больше пары минут сообщения молча отбрасывались (в журнале ничего не появлялось). Теперь возраст сообщения считается по времени сервера.
- На экране видно состояние связи: «Связь с сервером есть (сигнал N с назад)» или «Нет связи с сервером». В журнале есть строка «Подключено к серверу».
- Если Android остановил приём, при открытии Notify он запускается заново. Если система не дала запустить службу из фона, причина пишется в журнал.
- Сбои приложения записываются в журнал строкой «СБОЙ приложения».
- Кнопка «Настройки приложения»: там на Xiaomi и подобных телефонах нужно включить автозапуск и «Всплывающие окна в фоне».
